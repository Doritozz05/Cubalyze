# 16 User

## Purpose

Documentación orientada al usuario final de cada parte de la aplicación:
cómo funciona cada vista/tab, qué flujos tiene y qué guarda.

## Contents

- [`Training_View.md`](./Training_View.md) — tab **Training**: práctica por
  método/fase, calendario y repaso SRS (FSRS). (Con ADR-024 y TDD-0001.)
- [`Algorithms_View.md`](./Algorithms_View.md) — tab **Algorithms**: explorador
  del catálogo, diagramas 2D/3D, editor de algoritmos y puente a Training.
- [`SkillTree_View.md`](./SkillTree_View.md) — tab **SkillTree**: árbol de
  habilidades con prerrequisitos y progreso persistido.
- [`Reconstructions_View.md`](./Reconstructions_View.md) — tab **Reconstructions**:
  explorador de reconstrucciones + detección propia de fases.
- [`Cube_View.md`](./Cube_View.md) — tab **Cube**: simulador 3D inmersivo.
- [`Profile_View.md`](./Profile_View.md) — tab **Profile**: centro de identidad
  con datos reales de Stats/Training/Algorithms/Skills.
