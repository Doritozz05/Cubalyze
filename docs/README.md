# CubeForge Documentation Ecosystem

Welcome to the CubeForge Documentation repository. This `docs/` folder is the **Single Source of Truth** for the entire project.

## Directory Structure

The documentation is organized sequentially to match the software development lifecycle:

- `00-product/` - Product requirements and vision.
- `01-roadmap/` - Strategic roadmap and planning.
- `02-architecture/` - High-level system design.
- `03-adr/` - Architecture Decision Records.
- `04-rfc/` - Requests for Comments (Proposals).
- `05-tdd/` - Technical Design Documents (Implementation plans).
- `06-api/` - API specifications.
- `07-database/` - Database schemas and migrations.
- `08-standards/` - Coding and engineering standards.
- `09-testing/` - Test strategies and plans.
- `10-security/` - Threat models and privacy policies.
- `11-devops/` - CI/CD and deployment guides.
- `12-sdk/` - SDK documentation.
- `13-plugins/` - Plugin ecosystem rules.
- `14-ai/` - AI Agent instructions (`AGENTS.md`) and manifests.
- `15-contributing/` - Contribution guidelines.
- `16-user/` - End-user documentation.
- `17-releases/` - Changelogs.
- `18-archive/` - Deprecated and historical documents.

## AI-First Development

This repository is optimized for AI-assisted development. All AI agents must abide by the rules defined in [`14-ai/AGENTS.md`](./14-ai/AGENTS.md).
