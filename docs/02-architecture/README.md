# Cubalyze Architecture Workspace

Welcome to the Cubalyze Architecture Workspace. This directory is the authoritative source for all technical decisions, exploration, and system design.

## Structure and Responsibilities

To prevent mixing research with the established truth, this workspace is strictly divided into the following domains:

- **`overview/`**: The Current State of Truth. High-level explanations of how the system works *right now*. If an ADR is accepted, these documents are updated.
- **`research/`**: Exploration of alternatives. Contains the `Architecture_Research_Roadmap.md` and investigative reports. These are *not* final decisions.
- **`validation/`**: Hard data. Benchmarks, prototypes, and experiments that prove the research.
- **`diagrams/`**: Visual documentation (Mermaid, Draw.io) representing the system architecture.
