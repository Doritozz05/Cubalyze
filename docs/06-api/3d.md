## `@cubalyze/cube-3d-engine` — motor 3D (39 archivos)

**Propósito:** motor de renderizado del cubo con **Three.js puro** (ADR-014,
sin react-three-fiber). Render de cubies, materiales, animaciones de giro,
raycasting, y parsers de estado (incl. `parseFaceletsToCubies2x2`).

- **API:** re-exports `*` (escena, cubies, materiales, animación, cámara,
  interacción) + `parseFaceletsToCubies2x2`/`ParsedCubie2x2`.
- **Dependencias:** `three`, `three-stdlib`, `@cubalyze/math-core`,
  `@cubalyze/types`, `rxjs`, `comlink`.
- **Consumido por:** web (vista Cube, paneles 3D de Algorithms, widget
  cube-button, Case3DDiagram), desktop (Tauri).
- **Diseño:** [TDD-0006](../../05-tdd/TDD-0006-3D-Engine.md) — motor, materiales
  pooling, raycaster optimizado para móvil, animaciones con lerp/slerp fuera del
  ciclo de React.
